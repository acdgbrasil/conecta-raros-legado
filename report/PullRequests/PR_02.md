# PR_02 - Consolidação de Arquitetura, IAM, DevOps e Auditoria

## Título
Migração para Bun Workspaces, Refactor de IAM/Auth, Modernização de Infraestrutura (Ops) e Hardening

## Contexto
Este PR consolida a nova base arquitetural (Bun Workspaces) e a refatoração completa do módulo IAM. Além disso, **reestrutura completamente a camada de DevOps** (`ops/`), atualizando bancos de dados e criando ferramentas de automação (`make commit`) para garantir padronização e produtividade.

## Escopo (Alto Nível)
- **DevOps & Infra:** Criação da pasta `ops/`, decomposição do Docker Compose e atualização de bancos (PG 18, Mongo 8).
- **Automação:** Implementação de `Makefile` robusto e script de commit semântico.
- **Arquitetura:** Migração para Bun Workspaces e base de Data Governance.
- **IAM/Auth:** Refatoração do fluxo de autenticação e permissão.
- **Segurança:** Remoção de segredos hardcoded e migração para variáveis de ambiente.
- **Limpeza:** Remoção de legado (`conecta-social-front-old`) e arquivos raiz desnecessários.

## Principais Mudanças (Por Área)

### 🛠️ DevOps e Infraestrutura (NOVO)
- **Estrutura:** Centralização de arquivos Docker e scripts na pasta `ops/`.
- **Docker Compose:** Decomposição em `compose.infra.yml` (Bancos/Proxy) e `compose.yml` (Apps).
- **Updates de Banco:**
    - PostgreSQL atualizado para versão **18-alpine**.
    - MongoDB atualizado para versão **8.0**.
- **DX (Developer Experience):**
    - `make commit`: Script interativo para garantir Conventional Commits.
    - `make back`: Modo leve para rodar apenas o backend.
    - `make dev`: Modo completo com Hot Reload e Docker Watch.

### 🏗️ Arquitetura e Governança
- Adoção de **Bun Workspaces** e organização de módulos.
- Catalogação de dependências e limpeza de `package.json` raiz.

### 🔐 IAM/Auth
- Refatoração completa do Auth para suportar novo modelo de permissão.
- Finalização da rota de login no novo módulo IAM.
- Ajustes em entidades, mappers e migrations.

### 🛡️ Segurança
- Remoção de chaves JWT hardcoded e migração para `env`.
- Logs do Docker configurados para rotação automática e menor verbosidade.

## Riscos e Notas
- **Banco de Dados:** A atualização para PG 18 e Mongo 8 exige **reset dos volumes** (`make clean`). Dados antigos de desenvolvimento serão perdidos.
- **Ambiente:** É necessário rodar `make migrate` e `make seed` após subir o ambiente pela primeira vez.
