This is a parallel, AI-friendly documentation set for Mongoose 9.x. It is optimized for CLI agents and humans who want a clear, chapter-based path with practical guardrails and "good/bad" examples.

## How to use this doc
- Read chapters in order if you are new to Mongoose.
- Jump to specific chapters for deep topics (transactions, populate, TypeScript, migrations).
- Each chapter contains checklists and good/bad examples to validate your usage.
