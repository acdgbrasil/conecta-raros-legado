# Zod v4 Migration & Docs

Esta pasta contém a documentação oficial e guias de migração do Zod v4, utilizados como referência para a padronização dos nossos Mappers.

## Arquivos
- `MIGRATION_ZOD.MD`: Guia de breaking changes da v3 para v4.
- `ZOD_V4.MD`: Release notes e novas features.
- `definition_schemas.md`: Guia de sintaxe para definição de schemas.
