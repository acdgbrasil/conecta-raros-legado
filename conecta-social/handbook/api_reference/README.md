# API Reference & Curls

Guia de integração com os módulos ativos.

## 📌 Padrões Globais
- **Base URL:** `http://localhost:3000/api`
- **Content-Type:** `application/json`
- **Auth:** Bearer Token (JWT) no header `Authorization`.

## Módulos Disponíveis
- [🔐 IAM](./iam.md) - `/auth/*` e `/users/*`
- [🔔 Notifications](./notifications.md) - `/notifications/*`
