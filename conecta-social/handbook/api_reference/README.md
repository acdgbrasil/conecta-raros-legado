# API Reference & Curls

Guia de integração com os módulos HTTP ativos.

## 📌 Padrões Globais
- **Base URL:** `http://localhost:3000`
- **Content-Type:** `application/json`
- **Auth:** Bearer Token (JWT) no header `Authorization` quando aplicável.

## Módulos Disponíveis
- [🔐 IAM](./iam.md) - BFF web/mobile em `/iam/*`
- [🔔 Notifications](./notifications.md) - Webhooks futuros (sem endpoints ativos públicos)
