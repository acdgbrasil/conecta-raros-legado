# Domain Questions & Context Maps

Esta pasta organiza os estudos de domínio por bounded context. Cada subpasta replica o fluxo: introdução → mapa de contexto → capítulos detalhados.

- `iam/` consolida decisões de identidade, autenticação e autorização.
- `notifications/` consolida decisões de mensageria e estratégias de entrega.
- Novos contextos devem seguir a mesma convenção, numerando arquivos para guiar leituras sequenciais.

Use estes artefatos para guiar o ciclo RED → GREEN descrito no processo de engenharia.
