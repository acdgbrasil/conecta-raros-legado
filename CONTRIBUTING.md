# Contribuindo

Obrigado por considerar contribuir com o Conecta Social.

## Regras basicas
- Abra uma issue ou descreva o contexto antes de mudancas grandes.
- Evite incluir dados pessoais reais (PII) em commits, testes ou logs.
- Siga os padroes do handbook quando aplicavel.
- Consulte `SECURITY.md` para reporte de vulnerabilidades.

## Licenca e direitos
Ao enviar um pull request, voce concorda que:
- Seu codigo pode ser distribuido sob a licenca **CC BY-NC-SA 4.0**.
- Nao ha autorizacao para uso comercial do projeto.

Se voce nao concorda com esses termos, nao envie contribuicoes.
